# Sistema de Gestión de Ventas para Panaderías de Barrio

---

## 1. Contexto y Problemática

Las panaderías de barrio ocupan un lugar particular dentro del comercio minorista: son negocios de alta rotación, márgenes ajustados y una dinámica de venta rápida, muchas veces con varios productos despachados por minuto en el horario pico. 

Sin embargo, la gran mayoría de estos establecimientos sigue gestionando su operativa diaria mediante:
* Métodos manuales (cuadernos, planillas sueltas o calculadoras).
* Tickets escritos a mano.
* Sistemas de punto de venta (POS) genéricos que no se ajustan a la realidad y velocidad de un negocio de estas características.

---

## 2. Propuesta del Proyecto

Este proyecto propone el desarrollo de un **sistema de gestión de ventas** pensado específicamente para panaderías de pequeña y mediana escala (negocios familiares, de barrio o de un solo local). 

### Objetivos principales
1. **Simplicidad:** Ofrecer una herramienta accesible y fácil de usar en el mostrador.
2. **Control:** Permitir un registro ágil de las ventas diarias y un monitoreo preciso del inventario.
3. **Decisión:** Facilitar información real para la toma de decisiones, eliminando la complejidad y el costo de las soluciones orientadas a cadenas o grandes superficies.
